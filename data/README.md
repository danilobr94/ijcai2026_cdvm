# data/

Intermediate and precomputed artifacts used by the experiment scripts and plot notebooks.

## Storage

| Directory / File | Size | In Git | Source |
|---|---|---|---|
| `attr_datavals/` | small | ✓ | generated by `run_cdvm.py` |
| `attr_selected_vals/` | small | ✓ | generated by `run_cdvm.py` |
| `weights/` | small | ✓ | generated by `run_attr_computation.py` |
| `attr_matr/` | ~7.8 GB | ✗ | download (see below) |
| `influence_score_matrix-*.npy` | ~200 MB total | ✗ | download (see below) |

Large files are excluded from git and hosted on OwnCloud. Run from the repo root to fetch them:

```bash
python download_data.py
```

## Directories

### `attr_datavals/`

Per-run CDVM data value vectors. Each file is a `float64` array of shape
`(num_train,)` containing the attribution score for every training point.

### `attr_selected_vals/`

Per-run grid-search results. Each file is a pickled dict with keys:

| Key | Description |
|-----|-------------|
| `alpha` | Selected regularization strength |
| `max_val` | Selected max-value threshold |
| `score` | Validation accuracy of the selected configuration |

### `attr_matr/` *(not in git — download required)*

Full attribution matrices computed by `run_attr_computation.py`. Required to run
`run_cdvm.py` without recomputing them from scratch (~7.8 GB, several hours of compute).

Filename schema:
```
{dataset}-{num_models}_{prob}_{epochs}_batch_{i}.npy
```

| Field | Example | Description |
|-------|---------|-------------|
| `dataset` | `nomao` | Dataset name |
| `num_models` | `5000` | Ensemble size |
| `prob` | `0.03` | Dropout probability |
| `epochs` | `15` | Training epochs |
| `i` | `0` | Experiment index |

### `influence_score_matrix-LogisticRegression{dataset}.npy` *(not in git — download required)*

Precomputed LiSSA influence score matrices used by `run_pruning.py`.
Shape `(1000, num_params)`, `float32`. Computing from scratch takes several hours
per dataset; `rerun=False` in `run_pruning.py` skips recomputation when present.

| File | Shape |
|------|-------|
| `…adult.npy` | (1000, 218) |
| `…nomao.npy` | (1000, 180) |
| `…pol.npy` | (1000, 98) |
| `…bbc-embeddings.npy` | (1000, 3845) |
| `…cifar10-embeddings.npy` | (1000, 20490) |
| `…imdb-embeddings.npy` | (1000, 1538) |

### `weights/`

Cached initial model weights, written and read by `run_attr_computation.py` to
ensure consistent initialization across attribution matrix runs.
